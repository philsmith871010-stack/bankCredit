# Counterparty screen designs

Generated by `gen.py` from real figures captured 6 September 2026 (Nationwide Pillar 3 Q1 2026/27 KM1, Barclays, HSBC, NatWest and Skipton H1 2026 reports, EBA hub December 2025 ratios, ESMA register ratings, ICE and DTCC CDS). Visual system matches PWLBtoday's `tokens.css`: navy `#0a2540` gradient shell, orange `#fd7e14` accent, background `#f7f8fa`, Inter with IBM Plex Mono for numbers, radii 6, 10 and 14, navy table heads with orange labels.
